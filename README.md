# The Engine

A responsive, local-first educational capital rotation planner. Open `index.html` directly in a browser. No dependencies or build command.

## Publish with GitHub Pages
1. Create a new GitHub repository named `the-engine`.
2. Upload `index.html` and `README.md` to its default branch.
3. In Settings → Pages, select Deploy from a branch, the default branch, and `/ (root)`, then Save.
4. GitHub displays the published URL after deployment.

The planner uses manual assumptions, not live market prices. It does not connect to accounts or execute trades. The protection-first gate, risk allocation, yield and tax estimates, and market thresholds are illustrative. Local storage retains plan inputs in the browser; no backend.
